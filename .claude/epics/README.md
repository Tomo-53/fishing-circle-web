# epics — 案件知識層（完了するたびに賢くなる仕組み）

このディレクトリは、AI エージェントが「作業を通じて成長する」ための **案件（エピック）ごとの知識ノート** を置く場所です。
静的な規約（グローバル `CLAUDE.md` / 領域 `.claude/rules/`）に対して、ここは **動的に蓄積される知識** を担います。

## 3階層の知識

エージェントは上から順に読み込み、常にプロジェクトの文脈を把握します。

| 階層 | 役割 | 場所 |
|------|------|------|
| グローバル | 全共通ルール | ルート `CLAUDE.md` |
| 領域 | ファイル種別・領域ごとの規約 | `.claude/rules/` ＋ `src/**/CLAUDE.md` |
| **案件** | その案件の全記録（決定/前提/学び/未解決） | **`.claude/epics/<slug>/_epic.md`** |

## ディレクトリ構成

```
.claude/epics/
├── _TEMPLATE.md          # 案件ノートの雛形（コピー元・編集しない）
├── README.md             # このファイル
└── <slug>/               # 1 エピック = 1 機能（基本は 1 feature/ ブランチ）
    ├── _epic.md          # 案件ノート（知識の永続化先）
    └── tasks/            # 個別タスク（完了後に削除可。知識は _epic.md へ昇格）
        └── NNN-xxx.md
```

## 使い方（コマンド）

| コマンド | 役割 |
|---------|------|
| `/epic-new <名前>` | 新しい案件ノートを `_TEMPLATE.md` から生成 |
| `/epic-done` | 直近の作業から決定/前提/学びを抽出し `_epic.md` へ昇格、完了タスクを整理 |
| `/next` | `_epic.md` の未解決事項から次タスクを 1 つ提案（わんこそば配膳） |

詳しい昇格手順は `.claude/skills/epic-knowledge/SKILL.md` を参照。

## 命名規約

- `<slug>` は半角英小文字・数字・ハイフン（例: `catch-post`, `member-approval`）。
- 1 案件 = 1 `_epic.md`。原則として 1 `feature/` ブランチに対応させる。

## 機密を書かないこと（重要）

案件ノートは Git 管理に乗りチームで共有される知識資産です。以下は **絶対に書かないでください**（`.claude/rules/security.md`）。

- 個人情報（実名・連絡先など）
- 釣果の正確な座標・ポイント名などの保護対象情報
- `.env` の値・`APP_KEY`・パスワード・APIキー等の認証情報

これらは「○○は環境変数で管理」「座標は非公開」のように、値を伏せた形で記録します。
